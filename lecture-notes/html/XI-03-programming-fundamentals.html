0. Computers are obedient, not clever

A computer does nothing until a program — a list of instructions — tells it what to do. A programming language is the agreed vocabulary and grammar for those instructions. Python is a high-level language: it looks like structured English, not like raw $0$s and $1$s.

Low-level
Binary machine code. Fast for the chip, painful for humans.
Mid-level
Assembly or C-like languages: mnemonics plus some hardware control. C++ sits near this border and is used for systems and games.
High-level
Python, Java, C++. Designed for people. Java’s motto is “write once, run anywhere.” Python is the course language because it is readable and has a huge library world.
Careers
Python pays the rent in web work (Django, Flask), data science, AI, and automation. This unit is not “toy coding”; it is the on-ramp those fields share.

1. The workshop — VS Code and a first program

An IDE (Integrated Development Environment) is an editor plus runner plus debugger. Visual Studio Code is the recommended desktop IDE. Online runners such as online-python.com are acceptable when a lab PC is locked down.

1
Install VS Code. Install the Python extension. Confirm python --version in the terminal.
2
Save a file as hello.py. Run it with the play button or python hello.py.
3
Read the terminal. That window is part of the program, not decoration.

2. Variables, types, input, output

A variable is a named box. Names: letters, digits, underscore; must start with a letter or _; case-sensitive; cannot be a keyword (if, for, class…). Python infers the type from the value you put in the box.

Watch
input() always returns a string. Adding "3" + "4" gives "34". Wrap with int() or float() before any arithmetic.

4. Control structures — sequence, selection, repetition

Almost every program is assembled from three shapes.

4.1 Sequence

Statements run top to bottom. Default behaviour.

print("Enter two numbers")
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
total = a + b
print("Sum =", total)

4.2 Selection — if, if-else, elif

A colon ends the condition. The following indented block runs only when the condition is true. A lone if may do nothing; if-else always runs exactly one of the two blocks.

age = int(input("Enter your age: "))
if age >= 18:
    print("You are an Adult.")
    print("You are eligible to vote.")
elif age >= 13:
    print("Teenager — wait a few years to vote.")
else:
    print("Too young to vote.")
print("Program continues...")

4.3 Repetition — for and while

for i in range(5):        # 0,1,2,3,4
    print(i)
for i in range(2, 8):     # 2..7
    print(i)
for i in range(0, 10, 2): # step 2
    print(i)

count = 1
while count <= 5:
    print(count)
    count += 1            # forget this → infinite loop

break leaves the loop immediately. continue skips the rest of this iteration. Nested loops: the inner loop finishes a full cycle for every single outer step (this is why nested loops smell like $O(n^2)$).

\[ \texttt{range}(a,b) = \{a,a+1,\ldots,b-1\}, \qquad \texttt{range}(a,b,s)\text{ steps by }s. \]

6. Debugging — three families of pain

1. Syntax
The program never starts. Missing ), forgotten :, bad indent after if.
2. Runtime
Starts, then crashes. 10/0, int("abc"). Read the traceback: type, file, line.
3. Logical
Runs, prints the wrong answer. Classic: i -= 1 instead of i += 1 in a while — infinite loop that looks “alive”.

Self-check

  1. What does print(3 + int("4")) print? What about print(3 + "4")?
  2. Rewrite “print all odd numbers from 1 to 15” with range and a step.
  3. Name the error family: the program prints a negative average for a class of positive marks.
Answers. (1) $7$; the second raises TypeError. (2) for i in range(1, 16, 2): print(i). (3) Logical — it ran.

Recap

  1. Python is high-level; input() is always str.
  2. Names: letter/underscore first; case matters; no keywords.
  3. Operators: arithmetic, assignment, relational, logical, membership, bitwise.
  4. Sequence / selection / repetition. Indentation defines blocks.
  5. range(a,b) stops before $b$. break exits; continue skips.
  6. Import math, random, datetime; install third-party with pip.
  7. Debug by family: syntax, runtime, logical. Trust the traceback line number.
