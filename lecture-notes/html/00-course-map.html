How these notes were built. Each booklet follows the official intermediate syllabus units (digital systems through digital entrepreneurship). Every chapter is a single HTML file: Flexbox cards for comparisons, inline SVG for gates/stacks/networks, and MathJax for the notation an examiner expects. Chrome prints the same file to the PDF you are holding.

Study rule: read one section, redraw the figure from memory, then attempt the self-check before you turn the page.

Companion to the Class XI / XII Computer Science textbooks · not a replacement for practicals (LogiSim, Access, Figma, Python labs)

Notation you will keep meeting

\[ Y = A\cdot B + \overline{C}, \quad \mathit{MID}=\left\lfloor\frac{\mathit{BEG}+\mathit{END}}{2}\right\rfloor, \quad T(n)=O(\log n), \quad \bar{x}=\frac{1}{n}\sum x_i, \quad z=w\cdot x+b \]
Flexbox in these notes
Comparison cards, badge rows, two-column explainers, and the SDLC/IoT/sprint strips are all display:flex so a printed page and a browser window share one layout language.
SVG, not screenshots
Gates, waves, OSI stacks, stacks/queues, and neural nets are line diagrams you can re-sketch in an exam hall. If you cannot redraw it, you do not own it yet.
MathJax
Boolean algebra, Big-O, statistics, and the neuron sum are typeset with MathJax 3 (SVG output) so PDF and HTML stay sharp when zoomed.

Suggested weekly rhythm

  1. One booklet section a sitting (not a whole unit in one night).
  2. Redraw the figure; write the formula without the booklet.
  3. Do the self-check; only then peek at the answers.
  4. Transfer the idea into the lab tool of that unit (LogiSim, Python, Access, Figma, a paper MVP).
