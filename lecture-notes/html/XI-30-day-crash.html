Analog, digital, and the bit

Unit 1 · Computer Systems · 120-minute coached session

10 minRecall, cold
25 minTeach from the board
25 minWork the example together
40 minSilent drill, then mark
20 minHomework set and traps
Leave able to
  • Separate discrete from continuous
  • Sketch sine and square waves
  • State what 0 and 1 mean in a digital system
Trap that costs the mark

Calling every number on a screen ‘analog’. A digital display can show 37.4 and still be a digital system.

Board notes

A discrete quantity jumps between countable values: students in a room, books on a shelf. A continuous quantity can sit anywhere in a range: temperature, height, speed. Stairs are discrete. A ramp is continuous. Digital machines chose the stairs.

A signal carries information. An analog signal changes smoothly (voice, guitar, old telephone voltage) and is easily bent by noise. A digital signal has only HIGH and LOW, so a slightly dented pulse is still read as a bit.

\[ 0 = \text{OFF / LOW / FALSE}, \qquad 1 = \text{ON / HIGH / TRUE} \]
AnalogDigital
ValuesAny value in a rangeTwo levels
WaveSmoothSquare
NoiseCorrupts the valueUsually ignored
ExamplesVoice, vinyl, mercury thermometerPC, phone, USB, HDMI

Worked example — do not skip the steps

Board. A clinic stores body temperature. The mercury thermometer is analog. The digital thermometer stores $37.4$ after rounding to one decimal — still a number on a screen, but the electronics inside use bits. Ask: which representation survives a noisy cable? The bit stream. Which one can show a value between two marks without rounding? The analog instrument.

Write one sentence a marker can award: “Digital systems use two states so copies stay exact and noise rarely flips a solid HIGH into a solid LOW.”

Silent drill — cover the green model lines

1. Define discrete and continuous with one example each.

Model. Discrete: separate countable values (fingers on a hand). Continuous: any value in a range (speed of a car).

2. Why did engineers accept only two voltages?

Model. Two states are reliable against noise, exact when copied, simple to design, and easy to program.

3. Sketch labels, not art: which wave is HDMI?

Model. A square wave. HDMI is a digital signal, only HIGH and LOW.

4. Is ‘number of cars in a lot’ analog or discrete?

Model. Discrete. You cannot have 2.3 cars. The count jumps by whole cars.

5. A song on vinyl versus the same song as a file. One reliability difference.

Model. Vinyl (analog) picks up hiss; the file (digital) copies without that quality loss.
Tonight
Redraw both waves from memory and label three real devices under each.

Unit 1 · Computer Systems · 120-minute coached session

10 minRecall, cold
25 minTeach from the board
25 minWork the example together
40 minSilent drill, then mark
20 minHomework set and traps
Leave able to

  • Use Boolean + as OR
  • State precedence
Trap that costs the mark

Treating $+$ as ordinary addition. In this unit $1+1$ is 1.

Ten-minute recall — yesterday, closed book

AskAccept
What does bit 0 mean?OFF, LOW, or FALSE
Square wave or sine wave for USB?Square / digital

Board notes

George Boole’s algebra has two constants. Variables such as $A$ and $B$ hold only those constants. There are three basic operations.

OpSymbolRule
AND$A \cdot B$1 only when every input is 1
OR$A + B$1 when any input is 1
NOT$\overline{A}$ or $A'$Flips the single input
\[ 1+1 = 1 \quad \text{(OR, not arithmetic)} \]

Precedence, tightest first: brackets, then NOT, then AND, then OR. So $A + B \cdot C$ means $A + (B \cdot C)$.

Worked example — do not skip the steps

Board: $Y = \overline{A} + B$. Four rows, because $2^2 = 4$.

$A$$B$$\overline{A}$$Y$
0011
0111
1000
1101

The only 0 is row $A=1, B=0$. Say the English: “Y is 0 only when A is true and B is false.”

Silent drill — cover the green model lines

1. How many rows does a truth table with 3 inputs have?

Model. 8, because $2^3 = 8$. List inputs in binary counting order so no row is skipped.

2. Compute $1 + 1$ and $1 \cdot 0$ in Boolean algebra.

Model. OR: $1+1=1$. AND: $1 \cdot 0 = 0$.

3. Door with two locks. Which operation?

Model. AND. Both locks must be open. $Y = A \cdot B$.

4. Room with two doors. Which operation?

Model. OR. Either door is enough. $Y = A + B$.

5. Evaluate $A + B \cdot C$ when $A=0, B=1, C=0$.

Model. AND first: $B \cdot C = 0$. Then OR: $0+0=0$.

Expressions, precedence, universal gates

Unit 1 · Computer Systems · 120-minute coached session

10 minRecall, cold
25 minTeach from the board
25 minWork the example together
40 minSilent drill, then mark
20 minHomework set and traps
Leave able to
  • Evaluate a mixed expression row by row
  • Build NOT, AND, and OR from NAND
  • Draw $Y=(A+B)\cdot\overline{C}$
Trap that costs the mark

Forgetting the bubble when you copy a NAND into a diagram, which silently turns it into AND.

Ten-minute recall — yesterday, closed book

AskAccept
Universal gates?NAND and NOR
XOR of 1 and 0?1

Board notes

An expression is variables joined by operations. Add a column to the truth table for every sub-expression, left to right after applying precedence.

\[ Y = (A + B) \cdot \overline{C} \]

Order inside that formula: the bracketed OR, the NOT on $C$, then the AND. Three inputs means eight rows.

From NAND alone. NOT: $\overline{A} = \overline{A \cdot A}$ (tie both NAND inputs to $A$). AND: NAND followed by NOT. OR needs De Morgan: $A+B = \overline{\overline{A}\cdot\overline{B}}$, which is a NAND of two NOTs. You do not need the algebra name in the answer if you show the gates.

Worked example — do not skip the steps

Board row. $A=1, B=0, C=1$ in $Y=(A+B)\cdot\overline{C}$.

  1. $A+B = 1+0 = 1$.
  2. $\overline{C} = \overline{1} = 0$.
  3. $Y = 1 \cdot 0 = 0$.

Second row to speak aloud: $A=0, B=0, C=0$ gives $0 \cdot 1 = 0$. Third: $A=1, B=1, C=0$ gives $1 \cdot 1 = 1$.

Silent drill — cover the green model lines

1. Evaluate $A\cdot B + \overline{C}$ at $A=1,B=1,C=1$.

Model. AND first: $1\cdot 1=1$. NOT C is 0. OR: $1+0=1$.

2. How do you make a NOT from one NAND?

Model. Join both inputs of the NAND to the same variable. Output is $\overline{A}$.

3. Why eight rows for $Y=(A+B)\cdot\overline{C}$?

Model. Three input variables, and $2^3=8$.

4. Which operation is done first in $A+B\cdot C$ if there are no brackets?

Model. AND. The expression means $A+(B\cdot C)$.

5. Name the gate for ‘inputs different’.

Model. XOR.
Tonight
Pick one 3-variable expression and finish all eight rows. Do not stop at the interesting row.

DAY05

Minterms, maxterms, SOP and POS

Unit 1 · Computer Systems · 120-minute coached session

10 minRecall, cold
25 minTeach from the board
25 minWork the example together
40 minSilent drill, then mark
20 minHomework set and traps
Leave able to
  • Write a minterm for a row
  • Build SOP from the 1-rows
  • Build POS from the 0-rows
Trap that costs the mark

Numbering minterms out of binary order. $m_2$ is 10, not 01.

Ten-minute recall — yesterday, closed book

AskAccept
Precedence winner between AND and OR?AND
Rows for 3 inputs?8

Board notes

A minterm is an AND that contains every variable. If the variable is 0 in that row, write it complemented. You OR the minterms of every row where $Y=1$. That is the sum of products (SOP).

A maxterm is an OR that contains every variable, complemented when the variable is 1 in that row. You AND the maxterms of every row where $Y=0$. That is the product of sums (POS).

\[ m_0=\overline{A}\overline{B},\; m_1=\overline{A}B,\; m_2=A\overline{B},\; m_3=AB \]

The textbook prefers SOP when you draw the circuit: AND gates into one OR gate.

Worked example — do not skip the steps

Board. $Y=1$ only on rows $(0,1)$ and $(1,1)$.

SOP: $Y = \overline{A}B + AB$. Factor: $Y = B(\overline{A}+A) = B$. Check: both 1-rows have $B=1$, both 0-rows have $B=0$. The simpler answer is $Y=B$.

POS from the 0-rows $(0,0)$ and $(1,0)$: $Y = (A+B)(\overline{A}+B)$, which is also $B$. Either form is full marks if the rows are correct; the simplified form is the one you should draw.

Silent drill — cover the green model lines

1. Write $m_2$ for variables $A,B$.

Model. $A\overline{B}$. Row 2 is $A=1, B=0$.

2. SOP uses which rows?

Model. The rows where output $Y=1$.

3. POS uses which rows?

Model. The rows where output $Y=0$.

4. $Y=\overline{A}B + AB$. Simplify.

Model. $Y=B$.

5. Why does the course draw SOP as gates?

Model. Each product is an AND, and the sum of those products is one OR.
Tonight
From a blank 2-variable table with 1s only at $m_0$ and $m_2$, write SOP and simplify to $\overline{B}$.

DAY06

Karnaugh maps

Unit 1 · Computer Systems · 120-minute coached session

10 minRecall, cold
25 minTeach from the board
25 minWork the example together
40 minSilent drill, then mark
20 minHomework set and traps
Leave able to
  • Fill a map in Gray code
  • Group power-of-two cells
  • Read a group back as a term
Trap that costs the mark

Grouping three cells. Three is not a power of two; split into a pair plus a single, or find a pair and another pair.

Ten-minute recall — yesterday, closed book

AskAccept
SOP comes from which output rows?Y=1 rows
What is a minterm?AND of every variable, complemented where the row has 0

Board notes

A K-map is a truth table redrawn so neighbours differ by one bit (Gray code). Maurice Karnaugh, 1953. You circle groups of size $1, 2, 4, 8, \ldots$ — powers of two. Bigger groups make shorter expressions. Overlap is allowed. Edges wrap around, including corners on a 3-variable map.

Column order for three variables is $BC = 00, 01, 11, 10$. Never $00, 01, 10, 11$: that last pair is not adjacent in Gray code.

Inside a circle, drop any variable that changes, and keep any variable that stays constant (complemented if it stays 0).

Worked example — do not skip the steps

Board, two variables. Cells: $m_0=0, m_1=1, m_2=1, m_3=1$. That is $Y=\overline{A}B + A\overline{B} + AB$.

Group the bottom row ($A=1$, both columns) as $A$. Group the right column ($B=1$, both rows) as $B$. Overlap on $AB$ is legal. Result: $Y = A + B$. Check against the OR table: the only 0 is $A=B=0$.

Three-variable collapse the book likes. If every 1-cell contains $C$ and the pairs cover all of $A$ and $B$, the whole group reads $Y=C$.

Silent drill — cover the green model lines

1. Legal group sizes?

Model. Powers of two: 1, 2, 4, 8, …

2. Gray-code order of two bits?

Model. 00, 01, 11, 10.

3. May groups overlap?

Model. Yes. Overlap often gives the simplest cover.

4. A 2-cell group in which $A$ changes and $B$ stays 1. The term?

Model. $B$.

5. Simplify $Y=\overline{A}B + AB$ on a map or by factoring.

Model. $Y=B$.
Tonight
Draw a 2-variable map, place three 1s, circle, and write the OR expression without looking at today’s board.

  • Map four TCP/IP layers onto OSI

Trap that costs the mark

Saying OSI ‘is the Internet’. The Internet runs TCP/IP.

Ten-minute recall — yesterday, closed book

AskAccept
Transport PDU name?Segment
Layer of a MAC address?Data link

Board notes

TCP/IP is the model that actually runs the Internet: four layers, from 1970s US Department of Defense work. OSI (ISO, 1984) is the seven-layer teaching reference.

TCP/IPOSI layers folded inExamples
Application7 + 6 + 5HTTP, DNS, FTP, SMTP
Transport4TCP, UDP
Internet3IPv4, IPv6, ICMP
Network access2 + 1Ethernet, Wi-Fi, cables

Say this in the exam: OSI explains. TCP/IP implements.

Worked example — do not skip the steps

Board journey, college PC to a result website.

  1. Application builds the HTTP request.
  2. Transport wraps it as a TCP segment, destination port 443.
  3. Internet wraps that as an IP packet with the server address.
  4. Network access wraps a frame with the gateway MAC and sends bits.
  5. Each router looks at the IP, not the web page. The page is unwrapped only at the far host.

Silent drill — cover the green model lines

Model. Four.

2. Which TCP/IP layer holds Ethernet?

Model. Network access.

3. Which OSI layers does the TCP/IP application layer cover?

Model. Encapsulation: headers are added on the way down.

5. One line: OSI versus TCP/IP.
