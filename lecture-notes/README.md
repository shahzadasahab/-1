# Intermediate CS — Teach Yourself Lecture Notes

Self-study lecture notes aligned with **Intermediate (XI & XII) Computer Science** units. Each PDF is built from HTML that embeds:

- **MathJax** for formulas (Boolean algebra, complexity, statistics)
- **Inline SVG** diagrams (logic, OSI, HCI, decomposition, etc.)
- **CSS Flexbox** layout (cards, grids, callouts)

## Build

```bash
cd lecture-notes
npm install
npm run build
```

Outputs:

- `dist/html/` — one HTML file per unit
- `dist/pdf/` — printable A4 PDFs
