Programming:
Computer are dumb machines. They cannot think and do anything by themselves
without instructions. A set of instructions is called program and the language through
which we give instructions to computer is called programming language. It uses special

instructions can make the computer perform tasks like solving problems, playing games,
or running apps.

usually starts with comments, which are written using the # symbol. Comments are

finally shows the output. Python uses indentation (spaces at the beginning of a line) to
define blocks of code, instead of curly brackets. Indentation 1s mandatory in Python,
