Linear Time (O(n)): The execution time increases proportionally with the

each step until the target value is found or the search space is exhausted.
> Quadratic Time (O(m’)): The execution:-time increases proportionally to the

use nested loops, where each element is compared or processed against every

rapidly, making such algorithms inefficient for large datasets.
For Example: Comparing every item in a list with every other item, such as
when checking for duplicate values using two nested loops.

Queue:
A queue is a simple way of organizing data on First-In, First-Out (FIFO)
principle, where the order really matters, whoever comes first gets served first.
A good real-life example is a line at a ticket counter. The person who arrives
first stands at the front, and everyone else joins behind them. When it is time to be
served, the person at the front goes first, and the line keeps moving in order.
The process of adding an element to the “back” or “rear” of the queue is
called “Enqueue” and the process of removing an element from the “front” of the
queue is called “Dequeue”.
