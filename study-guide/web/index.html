Three questions: how does a machine represent truth with two states, how do teams turn an idea into software, and how do distant machines agree on a conversation?

1.1 Discrete versus continuous

A discrete quantity takes separate countable values (31 students, never 31.4). A continuous quantity can take any value in a range (temperature, height, time). Digital electronics copies the stairs: a wire is LOW (\(0\)) or HIGH (\(1\)).

1.2 Boolean algebra

George Boole’s algebra uses only \(\mathrm{FALSE}=0\) and \(\mathrm{TRUE}=1\). Precedence is

\[ (\,\cdot\,) \;\to\; \text{NOT }(\,'\,) \;\to\; \text{AND }(\,\cdot\,) \;\to\; \text{OR }(\,+). \]
  • AND: \(Y = A \cdot B = 1\) only if every input is \(1\).
  • OR: \(Y = A + B = 1\) if any input is \(1\).
  • NOT: \(Y = A' = \overline{A}\) flips one bit.

Worked evaluations. For \(A=1,\; B=0\): \(Y=A'+B = 0+0=0\). For \(A=1,\;B=0,\;C=1\): \(Y=(A+B)\cdot C = 1\cdot 1=1\). For \(A=B=C=1\): \(Y=A\cdot B + C' = 1 + 0 = 1\).

TRY THIS NOW
Evaluate \(Y=(A\cdot B)'+C\) for \(A=1,B=1,C=0\). Answer: NAND of \(1,1\) is \(0\), then \(0+0=0\).

1.3 The seven gates

A truth table with \(n\) inputs has \(2^n\) rows. List inputs in binary order so no row is skipped.

Derived identities you must write in math form:

\[ \begin{aligned} Y_{\mathrm{NAND}} &= (A\cdot B)' ,& Y_{\mathrm{NOR}} &= (A+B)' ,\\ Y_{\mathrm{XOR}} &= A\oplus B = A'B + AB' ,& Y_{\mathrm{XNOR}} &= (A\oplus B)' = AB + A'B'. \end{aligned} \]

NAND and NOR are universal: any Boolean function can be built from only NAND, or only NOR.

1.4 Expressions, diagrams, SOP

For \(Y = A\cdot B + C\) (three variables \(\Rightarrow 8\) rows) compute the helper column \(A\cdot B\), then OR with \(C\).

Sum of products: each row where \(Y=1\) is a minterm. If a variable is \(0\) in that row, complement it. Then

\[ Y = \sum \text{minterms of the 1-rows}. \]

Example: 1-rows \(AB=01\) and \(11\) give \(Y=A'B + AB = B\).

COMMON MISTAKE
In a minterm, a \(0\) in the row means the variable is complemented. Row \(A=0,B=1\) is \(A'B\), not \(AB'\).

1.5 Karnaugh maps

Adjacent cells (including wrap-around) differ by one bit — Gray code. Group \(2^n\) ones; the changing variables cancel.

TRY THIS NOW
Simplify \(Y=\sum m(0,1,2,3,5,7)\). Two groups of four give \(Y=A'+C\).

1.7 Communication models

TCP is connection-oriented and reliable (web, email, files). UDP is connectionless and cheap (live video, games). An IP address is logical; a MAC address is burned into the NIC. Routers live at Layer 3; switches at Layer 2; hubs at Layer 1. ping uses ICMP at the Network layer.

Unit 2 — Computational Thinking and Algorithms

Computational thinking is thinking so clearly that a machine — or another human — can follow you.

An algorithm is a finite, language-independent sequence of steps. Pseudocode writes those steps with IF/FOR/WHILE but no compiler syntax.

  • Decomposition — split “learn Spanish” into alphabet, vocabulary, grammar, practice.
  • Pattern recognition — a triangle of stars that grows by one star per row is a loop \(i=1\ldots n\).
  • Abstraction — making tea is boil, add, steep, pour. Ignore mug colour.
EXAM TIP
Ignoring the kettle brand is abstraction, not decomposition.

2.1 Bubble Sort

Compare neighbours; swap if out of order. After pass \(k\), the \(k\) largest items sit at the right. Nested loops give time that grows like \(n^2\).

FOR pass ← 0 TO n−2
    FOR i ← 0 TO n−2−pass
        IF DATA[i] > DATA[i+1] THEN swap

Strengths: in-place and stable. Weaknesses: time grows like \(n^2\); many swaps.

2.2 Selection Sort

On pass \(k\), find the minimum of the unsorted tail and swap it into index \(k\). At most one write per pass — fewer swaps than Bubble Sort, still \(\Theta(n^2)\) comparisons, not stable.

2.3 Searching

Linear search checks items \(1,2,\ldots,n\). Works on unsorted data. Worst case \(n\) probes.

Binary search requires a sorted array. Each step uses

\[ \mathrm{mid} = \left\lfloor \frac{\mathrm{low}+\mathrm{high}}{2} \right\rfloor. \]

If the target is smaller, set \(\mathrm{high}=\mathrm{mid}-1\); if larger, \(\mathrm{low}=\mathrm{mid}+1\). About \(\log_2 n\) probes — twenty looks for a million items.

COMMON MISTAKE
Binary search on an unsorted list is not “a bit worse.” It is wrong: the discarded half may hold the target.
LinearBinary
Needs sorted data?NoYes
IdeaOne-by-oneHalve the interval

Judge every algorithm on correctness (right for every valid input, and it finishes), efficiency (time and memory as \(n\) grows), and clarity.

Bitwise worked example. \(a=10=1010_{2}\), \(b=6=0110_{2}\):

\[ a \land b = 0010_{2}=2,\quad a \lor b = 1110_{2}=14,\quad a \oplus b = 1100_{2}=12,\quad a \ll 1 = 20 = a\cdot 2. \]

Unit 4 — Data and Analysis

Eighty, seventy-five, ninety is data. “The class average is 80%” is information. A database is the organised cupboard that keeps those facts consistent.

A DBMS (Access, MySQL, Oracle, SQL Server) inserts, updates, deletes, and retrieves with less redundancy, better consistency, security, and integrity. An RDBMS stores related tables.

KeyRole
CandidateAny unique non-null identifier — a table may have several
PrimaryThe chosen candidate; exactly one; never NULL
AlternateA leftover candidate
ForeignPoints at another table’s primary key; may repeat

Referential integrity: every foreign key must match a living parent. Cascade update rewrites child FKs when the parent PK changes. Cascade delete removes child rows when the parent is deleted — use it like a chainsaw.

Access objects: table stores, form enters, query asks, report prints. In Query Design, AND is the same criteria row; OR is different rows. Totals \(\Sigma\): Group By + Count/Avg/Sum/Min/Max. Line charts show trends; pies show parts of a whole; bars compare named categories.

  2. Qualitative, quantitative, or mixed.

Case studies and closed-book drills

Al-Noor Library — why Waterfall worked

1,200 students, 2,400 books, paper register, lost copies, handwritten overdue lists. Requirements were frozen: add/edit books, search, 14-day loans, overdue alerts, printed reports, offline Windows. Team of four, six months, Python + Tkinter + SQLite. Waterfall fitted because nothing experimental was asked. Testing (black box) found a search crash on misspellings and an overdue alert that ran only if a button was clicked. Both were fixed and retested. A two-week pilot sat on the librarian’s desk before students used it. Later maintenance: printer-driver fix (corrective), e-book category (adaptive), faster search (perfective), daily USB backup (preventive). Overdue returns fell about 70%.

Al-Noor Student App — why Agile worked

Nobody could list every feature on day one. Five two-week sprints, Flutter, five-person Scrum team. Sprint 1 shipped login + timetable; feedback added teacher names. Sprint 2 shipped exam results; parents then asked for a full attendance record. Sprint 3 shipped SMS absence alerts; when the gateway died for two days the team switched to email and kept moving. Sprint 4 connected to the library through an API and added an available-copies counter in thirty minutes. Sprint 5 shipped homework photos and fixed three launch bugs. Five of ten original stories shipped in ten weeks. That flexibility is the point of Agile.

DECISION RULE
Pacemaker firmware with a frozen regulator spec → Waterfall (late change can kill). A club-events app that will grow with student requests → Agile. Four lines in a notebook is a complete 4-mark compare.

Algorithm studio — same list, two sorts

Bubble Sort on \(\{6,2,5,1\}\): pass 1 → \(\{2,5,1,6\}\) (three swaps); pass 2 → \(\{2,1,5,6\}\); pass 3 → \(\{1,2,5,6\}\). Selection Sort finds min \(1\) and swaps once with \(6\) → \(\{1,2,5,6\}\). Fewer writes. Watch equal keys: Bubble Sort is stable; Selection Sort may swap two 4s.

Binary search for 11 in \(\{2,5,7,11,13,17,19\}\): \(\mathrm{mid}=\lfloor(0+6)/2\rfloor=3\), hit on the first probe. For 2 (left edge) you need three looks. For 12 (absent) you finish with \(\mathrm{low}>\mathrm{high}\) and report not found — write that failure case so you do not invent a crash.
